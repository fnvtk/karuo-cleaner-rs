# 卡若清理 · Karuo Cleaner

Rust 编写的 macOS 空间清理工具，内嵌中文界面与可配置 AI 对话助手。仓库：`karuo-cleaner-rs`。

## 功能

- 智能扫描、旧缓存与日志候选、大型和旧文件分析。
- 空间透镜：磁盘/大目录扫描、空间图、下钻、搜索与分页；支持勾选、右键和精确清理计划。
- 应用卸载与准确 Bundle ID 关联残留核对；保留共享数据、凭证和应用资料。
- 用户登录项列表、定时扫描/保守清理。
- 每模块独立后台扫描；切页保留任务和结果，无扫描文件数量截断。
- 板块内 AI 对话、匿名分类分析、待确认清理清单、定时设置草案。
- 移入系统废纸篓、最近批次撤回、历史恢复；本机同用户 API 可供 Codex 调用。

## 安装

在版本发布页下载 `KaruoCleaner-1.4.0-macos.zip`，解压后将「卡若清理.app」拖入 Applications。当前为本机构建与临时签名，尚未 Apple 公证；系统是否允许打开取决于本机安全策略。本项目不提供绕过系统保护的安装步骤。

## 构建

需要 macOS 13+、Rust 与 Xcode Command Line Tools。本次安装包为 Apple Silicon（arm64）；其他架构需在对应 Mac 上构建。

```sh
cargo fetch --locked
zsh scripts/build.sh
```

构建脚本离线使用已下载依赖，产物在 `dist/卡若清理.app`。

## AI 与 API

AI 接口、模型和密钥在应用设置中配置；密钥保存在本机应用支持目录，不包含在仓库或安装包中。自动上下文只发匿名角色与统计，不发送文件内容。模型建议不能绕过本机保护或直接指定任意删除路径。

[本机 API 说明](API/README.md)；使用示例：

```sh
'/Applications/卡若清理.app/Contents/MacOS/KaruoCleaner' --api '{"cmd":"capabilities"}'
```

## 验证与边界

41项测试通过，并用自建夹具验证扫描、移入废纸篓、恢复、AI清单和撤回。测试脚本只用于自建夹具，勿改为清理现有个人资料。

当前空间树只在本次运行中保留；其他模块完成列表可跨重启保存。最近批次撤回限本次启动，旧记录使用历史恢复。物理可回收空间可能受 APFS 共享块、压缩和快照影响。
