# 开发说明

卡若清理使用Rust实现本机窗口、扫描与文件保护，HTML/CSS/JS呈现界面。

## 构建

需要macOS13+、Rust、Xcode Command Line Tools。本次发布的安装包为arm64。

```sh
cargo fetch --locked
zsh scripts/build.sh
```

产物：dist/卡若清理.app。

[API文档](../API/README.md)包含扫描、清理计划、历史恢复、AI对话等接口。密钥仅放本机应用支持目录，不能提交到仓库。

空间树只本次运行保存；其他模块完成列表可跨重启保存。最近批次撤回限本次启动，旧记录走历史恢复。物理可释放空间取决于磁盘实际情况，不能把扫描大小等同可释放空间。

41项测试及自建夹具的移动、恢复、AI清单与撤回已验证。未Apple公证；不包含第三方原应用源码或二进制，也不宣称所有算法完全相同。
