# build 14：扫描进度与长任务体验

## 用户看到的问题
系统垃圾扫描时，界面虽然仍在读取，但状态总被刷新成固定的“正在扫描”，结果区显示空白等待，长任务看起来像没有进展。

## 修复
- 保留扫描器定期发出的当前阶段、已检查数量和候选数量，不再被结果刷新覆盖。
- 结果区同步显示当前扫描阶段与已运行时间，空结果列表也展示同一进度。
- 加入持续移动的进度条，并按模块保留扫描进度；切换页面不会取消扫描，返回后可继续查看。
- 扫描任务结束或手动取消后，清除运行计时和进度状态。

## 验证
构建后运行 Rust 单元测试、内置本机清理/恢复自检、前端脚本语法检查和 macOS 应用签名检查。正在使用的旧进程不会被强制退出；新进度体验需要重新启动到 build 14 后生效。
